## Issues

### 1. Memory Leak (Missing Cleanup)
**Location:** Inside the `useEffect` hook.
**The Problem:** `setInterval` is initialized but never cleared. If the component unmounts, the interval continues to run in the background, attempting to update the state of a non-existent component.
**The Fix:** Return a cleanup function that calls `clearInterval(interval)`.
```javascript
// ❌ Problem
useEffect(() => {
  const interval = setInterval(() => { ... }, 2000);
}, []);

// ✅ Solution
useEffect(() => {
  const interval = setInterval(fetchData, 2000);
  return () => clearInterval(interval); 
}, []);

```

### 2. Performance Bottleneck (Expensive Filtering)
**Location:** The `filteredUsers` constant.
**The Problem:** The `.filter()` and `.toLowerCase()` operations run on **every single render**. If the user list grows or the parent component re-renders, this causes unnecessary CPU usage and UI lag.
**The Fix:** Wrap the filtering logic in `useMemo`, ensuring it only recalculates when `users` or `filter` actually change.

```javascript
// ❌ Problem
const filteredUsers = users.filter(u =>
  u.name.toLowerCase().includes(filter.toLowerCase())
);

// ✅ Solution
const filteredUsers = useMemo(() => {
  return users.filter(u => u.name.toLowerCase().includes(filter.toLowerCase()));
}, [users, filter]);
```

### 3. Network Reliability (Error Handling)
**Location:** The `fetch` promise chain.
**The Problem:** The code assumes the API always succeeds. It doesn't check `res.ok` or catch network errors, which can lead to a broken UI state if the server goes down.
**The Fix:** Add a `.catch()` block and verify the response status.
```javascript
// ❌ Problem
fetch('/api/users')
  .then(res => res.json())
  .then(data => setUsers(data));

// ✅ Solution
fetch('/api/users')
  .then(res => {
    if (!res.ok) throw new Error('Failed to fetch');
    return res.json();
  })
  .then(data => setUsers(data))
  .catch(err => console.error(err));
```
### 4. Uncontrolled Input
**Location:** The `<input>` element.
**The Problem:** The input lacks a `value` prop tied to the state. This makes it an "uncontrolled" component, which can lead to sync issues between the UI and the underlying state.
**The Fix:** Add `value={filter}` to make it a Controlled Component.

---
```javascript
// ❌ Problem
<input onChange={(e) => setFilter(e.target.value)} />

// ✅ Solution
<input 
  value={filter} 
  onChange={(e) => setFilter(e.target.value)} 
/>
```

## ✅ Complete Solution

```javascript

import React, { useState, useEffect, useMemo } from 'react';




/**
 * UserDashboard
 * Features: Auto-polling (2s), Memoized Search, and Memory Leak Protection.
 */
function UserDashboard() {
  const [users, setUsers] = useState([]);
  const [filter, setFilter] = useState("");

  useEffect(() => {
    const fetchData = async () => {
      try {
        const response = await fetch('/api/users');
        if (!response.ok) throw new Error(`Error: ${response.status}`);
        const data = await response.json();
        setUsers(data);
      } catch (err) {
        console.error("Failed to fetch users:", err);
      }
    };

    // Initial fetch
    fetchData();

    // Setup polling
    const interval = setInterval(fetchData, 2000);

    // FIX: Cleanup function to prevent memory leaks
    return () => clearInterval(interval);
  }, []);

  // FIX: Memoize expensive filtering logic
  const filteredUsers = useMemo(() => {
    const searchTerm = filter.toLowerCase();
    return users.filter(u => u.name.toLowerCase().includes(searchTerm));
  }, [users, filter]);

  return (
    <div className="dashboard">
      <input 
        type="text"
        placeholder="Search users..."
        value={filter} // FIX: Controlled component
        onChange={(e) => setFilter(e.target.value)} 
      />
      
      <div className="user-list">
        {filteredUsers.length > 0 ? (
          filteredUsers.map(user => (
            <UserCard key={user.id} user={user} />
          ))
        ) : (
          <p>No results found.</p>
        )}
      </div>
    </div>
  );
}

export default UserDashboard;
